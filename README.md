# 🚀 Featured Project

## 🔔 PushRocket

**PushRocket** is a hybrid push notification platform designed to convert anonymous website visitors into engaged users through targeted, automated, and real-time notifications.

### 🧰 Built With

`Laravel` `NodeJS` `MySQL` `Firebase` `WebPush`

### ✨ Key Features

* 🔔 Web Push Notifications
* 🔥 Firebase Cloud Messaging (FCM)
* ⚡ Real-time notifications
* 📅 Automated campaign scheduling
* 🔄 Laravel Scheduler
* 📦 Laravel Queues
* 🚀 Job Batches for bulk processing
* 🔁 Retry and failure handling
* 🌐 Multi-website communication
* 📊 Campaign and delivery tracking

### ⚙️ Architecture

```text
                    ┌─────────────────────┐
                    │     Website Users   │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │      PushRocket     │
                    │      Laravel API    │
                    └──────────┬──────────┘
                               │
                    ┌──────────┴──────────┐
                    │                     │
                    ▼                     ▼
             ┌─────────────┐       ┌─────────────┐
             │    MySQL    │       │    Queue    │
             │   Database  │       │   Workers   │
             └─────────────┘       └──────┬──────┘
                                          │
                                          ▼
                              ┌─────────────────────┐
                              │ Firebase / WebPush  │
                              └──────────┬──────────┘
                                         │
                                         ▼
                              ┌─────────────────────┐
                              │     End Users      │
                              └─────────────────────┘
```
