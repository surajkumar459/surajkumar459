<h3 align="center">🔔 PushRocket</h3>

  through targeted, automated, and real-time notifications.
</p>

### ✨ Key Features

| Feature | Description |
|:--|:--|
| 🔔 **Web Push Notifications** | Reach visitors directly in their browser |
| 🔥 **Firebase Cloud Messaging (FCM)** | Reliable cross-platform delivery |
| ⚡ **Real-time Notifications** | Instant delivery to end users |
| 📅 **Campaign Scheduling** | Automated using Laravel Scheduler |
| 📦 **Laravel Queues** | Background processing for heavy tasks |
| 🚀 **Job Batches** | Bulk processing at scale |
| 🔁 **Retry & Failure Handling** | Resilient delivery pipeline |
| 🌐 **Multi-website Communication** | Manage multiple sites from one platform |
| 📊 **Campaign & Delivery Tracking** | Monitor performance and delivery status |
